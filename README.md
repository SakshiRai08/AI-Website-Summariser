An AI agent that scrapes any website and gives you concise summary using Groq(openai/gpt-oss-20b) + Gradio.

### Demo
Live: 'http://127.0.0.1:7860' (local)
public: https://ai-website-summariser.onrender.com/

### Tech Stack
- Python, BeautifulSoup, Requests
- Groq API(openai/gpt-oss-20b)
- Gradio UI

### Features
- Paste any URL -> Get instant summary
- Handles large websites (token truncation fix)
- Clean Gradio interface

### Run Locally
pip install -r requirements.txt
python app.py
